# 용용사주 로컬 복제본

[용용사주](https://yongyong.ai/)의 공개 웹 화면을 REA로 관찰하고, 원본이 내려주는 HTML·CSS·자바스크립트·이미지·폰트·미디어를 로컬로 저장했습니다. 로컬 서버에서 원본 프런트엔드를 실행합니다.

## 실행

Node.js 22 기준입니다. 프로젝트 폴더에서 `npm start`를 실행하고 [http://127.0.0.1:4173](http://127.0.0.1:4173/)에 접속하세요. 저장된 `mirror-data/`가 있으면 설치나 외부 연결 없이 실행됩니다.

다른 머신에서 스냅샷을 다시 만들려면 인터넷에 연결한 상태에서 `npm run capture`를 실행하세요. 이 명령은 REA로 확인한 공개 경로와 그 경로에서 참조하는 자산을 GET으로 저장합니다. `mirror-data/`는 용량이 큰 생성 데이터라 Git에서 제외합니다. 저장된 파일을 다른 머신으로 복사해서 실행할 수도 있습니다.

## 재현 범위

- 원본 모바일·데스크톱 화면, 캐러셀, 메뉴, 카테고리, 검색과 공개 상품 상세를 로컬에서 엽니다.
- 운세·보관함·내 정보와 관찰된 공개 하위 페이지를 로컬에서 제공합니다.
- 상품 입력 화면은 원본 자바스크립트로 동작합니다. 게스트 등록과 익명 보관함 조회는 로컬 서버에서 처리합니다.
- 조회한 공개 상품 정보와 후기 응답은 저장 시점의 데이터입니다. 일부 원본 자산이 삭제되었거나 수집 당시 요청에 실패한 항목은 `mirror-data/index.json`의 `missing`에 기록됩니다.

공개 일주 값은 서울 날짜를 기준으로 로컬에서 계산합니다. 비로그인 만세력 조회는 REA에서 확인한 인증 필요 응답을 재현하며, 가입 화면까지 로컬에서 엽니다.

## 로컬 서버 리포트

상품 입력 화면의 **로컬 서버 리포트 만들기**를 선택하면 로컬 서버가 입력 날짜와 고민 주제를 바탕으로 리포트를 작성합니다. 같은 브라우저에서 보관함과 이전 결과를 다시 열 수 있습니다. 리포트는 `mirror-data/local-reports/`에 저장됩니다. 원본 출생일과 고민 원문은 저장 파일에 포함되지 않습니다.

이 리포트는 로컬 규칙 기반 해석이며, 원본 용용사주의 유료 리포트와는 별도입니다. 원본 생성 API는 아래 테스트 서버 모드에서 연결합니다.

## 승인된 테스트 API 연결

독립 테스트 서버가 원본과 같은 `/dragon/...` API를 제공하면, PowerShell에서 그 서버의 오리진을 지정한 뒤 복제본을 실행하세요.

```powershell
$env:YONGYONG_SANDBOX_API = 'https://staging.example.com'
npm start
```

이 모드에서는 원본 프런트엔드의 API 요청이 테스트 서버로 전달됩니다. 테스트 계정과 외부 인증·결제 서비스의 콜백 주소는 테스트 환경에 등록해야 합니다. 브라우저에서 테스트 SDK나 결제 프레임을 열어야 하는 경우, 해당 테스트 HTTPS 오리진을 공백으로 구분해 `YONGYONG_SANDBOX_WEB_ORIGINS`에 지정합니다. [서버 상태](http://127.0.0.1:4173/__mirror/status)의 `apiMode`에서 연결 설정을 확인할 수 있습니다.

`npm test`는 로컬 테스트 서버로 요청 본문·인증 헤더·쿠키·리다이렉트와 스트리밍 응답 전달을 검증합니다. 실제 카카오 로그인, 결제, 리포트 생성 및 동기화 검증에는 해당 테스트 서버가 필요합니다.
